# Launch Brief

## Positioning

`ml-researcher-os` is for developers who already use coding agents and want them to behave more like careful ML research collaborators.

The project wins trust by showing discipline:

- explicit limitations
- reproducible examples
- small install path
- benchmark companion repo
- no autonomous-scientist hype

## First release scope

The first public release should include:

- one installable skill pack
- one tiny paper-to-experiment example
- one result report template
- one negative-results example
- one benchmark task in `agent-skill-bench`

## Launch surface

- GitHub repo direct link
- Hugging Face Space demo when available
- Dev.to technical article
- Hacker News Show HN
- Reddit technical post after the repo has real examples

## Messaging guardrails

Say:

- "helps agents follow a research protocol"
- "benchmarks whether skills help"
- "documents limitations"
- "small reproducible examples"

Avoid:

- "replaces researchers"
- "fully autonomous scientist"
- "guaranteed paper reproduction"
- "100K stars"
