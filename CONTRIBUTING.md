# Contributing

Thanks for helping build `ml-researcher-os`.

The project values reproducible examples, honest failure reports, and small improvements that make agent-assisted ML research less sloppy.

## Good first contributions

- Add a checklist for a common ML research failure.
- Add a tiny reproducible experiment.
- Improve a skill instruction with a clearer constraint.
- Add a negative example where an agent overclaimed.
- Improve the README or demo script.

## Contribution standards

- Keep examples small enough to run locally.
- Include expected outputs when possible.
- Separate facts from interpretations.
- State limitations clearly.
- Avoid benchmark claims without logs or artifacts.

## Pull request checklist

- [ ] The change is scoped and easy to review.
- [ ] New behavior is documented.
- [ ] Examples include expected outputs.
- [ ] Claims are supported by evidence.
- [ ] Limitations are not hidden.
